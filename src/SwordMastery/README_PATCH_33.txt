Sword Mastery PATCH33 - Full Body HD / Dash / CJK Display Fix

- Replaces 32x32 arm/weapon line overlay with 128x128 full-body pixel animation frames in 4 directions.
- Six action sequences: Step, Slash, Calico, Issen, Pinnacle and Footwork.
- FarmerSprite animations are not modified, preventing the previous dash cancellation.
- Dash movement is interpolated across several ticks with the original obstacle-tested endpoint preserved.
- Independently loads Japanese and Simplified Chinese SpriteFonts already included with Stardew Valley. No external font files.
- Text in the Sword Mastery skill tree and HUD displays in the selected mod language.
- Text displayed by the unmodified vanilla journal/item menus and GMCM uses the game font; if the mod language has different CJK glyphs from the game language, those texts fall back to English instead of ***.
- Does not change skill damage, skill points, save schema, quest logic or cooldowns.

LIMITATIONS: This test version temporarily uses a custom pixel-art full-body costume during skills. Hairstyles, hats and specific modded clothes are not reproduced yet.
GitHub Actions compilation success does not guarantee in-game visual correctness. In-game testing is still necessary.
