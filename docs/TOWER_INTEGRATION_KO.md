# 시련의 탑 연동 개발본 0.1.9-alpha.1

기반: release/0.1.8-patch44-fix04 (0cd1d86). Tower 동시 설치는 alpha.53/API4 이상을 요구한다. Tower 미설치/탑 밖에서는 기존 전투를 유지한다. 기존 GMCM 진행도 보호·WOL 처치 콜백 수정·구르기 잠금·애니메이션 소유권을 보존한다.

검 기술·검기·예약 다단 타격에 원본 검/발동 시점 장비 기록을 붙였다. 지연 명중 전에 무기를 교체해도 원본 기록을 사용하며, 탑 효과와 네이티브 처치를 한 번씩 수행한다. EW 공격 비율을 raw에 다시 곱하지 않는다. 확정 치명은 탑에 한 번 전달하고 게임의 두 번째 치명 굴림을 막는다. 이 경로의 기본 게임 피해 숫자 색은 일반색일 수 있으므로 인게임 표시 검증에 포함한다.

일반 휘두르기는 등록 소비자가 점유하지 않는다. 자동 궁극기 오라·비무장 기술·고정 마무리 피해는 기존 네이티브 처리다. API 거절/부분 실행 실패 후 원래 피해를 재시도하지 않는다. 기술 피해·쿨타임 수치는 바꾸지 않았다.

검증: 생산 어댑터11개, 기존 진행도/애니메이션/WOL/구르기 회귀 및 소스 계약, 실제 게임 참조 빌드. 구형 Harmony 2.3.3은 현재 Debian13 로더가 executable stack 요구를 거절하므로 로컬 실패를 기록하고 Ubuntu24.04 CI에서 확인한다. Harmony 2.4.2 회귀 및 참조 빌드는 통과했다. 실제 PC/Android·SMAPI API 프록시·멀티는 미검증이다. 외부 공방 각인 허용과 통합 실기는 후속이다.
